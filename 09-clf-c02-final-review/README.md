# 09 - CLF-C02 Final Review

## Objective

Validate practical readiness before taking the AWS Certified Cloud Practitioner (CLF-C02) exam.

This module is not intended to teach new concepts.

Instead, it serves as a final hands-on review to confirm familiarity with the AWS services, concepts, and terminology most commonly encountered on the exam.

Estimated time: 15-20 minutes

## Exam-Day Recommendations

### Before the Exam

* Review AWS service names
* Review common use cases
* Review pricing models
* Review IAM concepts
* Review AWS global infrastructure

---

### During the Exam

* Read every question carefully
* Identify keywords
* Eliminate obviously incorrect answers
* Focus on AWS-managed solutions
* Prefer simpler AWS-native services when appropriate

---

## Completion Criteria

You are likely ready for the CLF-C02 exam if:

* You understand the purpose of the core AWS services.
* You can identify the correct service for common business scenarios.
* You have completed the hands-on activities in this guide.
* You can navigate the AWS Console with confidence.
* You can explain fundamental AWS concepts without memorization.
